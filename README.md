# 🩺 Multiple Disease Prediction System

## 📌 Overview

The **Multiple Disease Prediction System** is a Machine Learning web application developed using **Python** and **Streamlit**. It predicts the likelihood of three diseases based on user-provided medical parameters:

* 🩸 Diabetes Prediction
* ❤️ Heart Disease Prediction
* 🧠 Parkinson's Disease Prediction

The application uses trained machine learning models to provide instant predictions through an easy-to-use web interface.

## ▶️ How to Run Locally

1. Clone the repository.
2. Install the required packages:

```bash
pip install -r requirements.txt
```

3. Run the application:

```bash
streamlit run "Multiple Disease Pred.py"
```
